# Repository working agreements

## Pull request creation

- Create a pull request only when the user explicitly requests a pull request.
- Requests to commit changes, push a branch, merge into main, or prepare PR-sized commits do not authorize creating a pull request.
- If no pull request was explicitly requested, complete the authorized Git operations without creating one.

## Commit messages

- Follow the Lore protocol: begin with an intent line explaining why the change was made, then add relevant narrative context and native Git trailers such as `Confidence:`, `Scope-risk:`, and `Tested:`.
